# 🔄 Обновление API URL для фронтенда

## 📋 Текущая ситуация

Фронтенд использует `REACT_APP_API_URL` из переменных окружения. Это правильно настроено.

## ✅ Что нужно сделать

### Шаг 1: Определить правильный URL

**Вариант A: Локальная сеть (для тестирования)**
```
http://192.168.2.170:8080
```

**Вариант B: Через Cloudflare Tunnel (для продакшена)**
```
https://api.yourdomain.com
```
(или ваш URL из Cloudflare Tunnel)

### Шаг 2: Обновить GitHub Secret

1. Зайдите в GitHub репозиторий
2. **Settings** → **Secrets and variables** → **Actions**
3. Найдите `REACT_APP_API_URL`
4. Нажмите **Update** (или создайте новый, если нет)
5. Вставьте правильный URL:
   - Для локальной сети: `http://192.168.2.170:8080`
   - Для продакшена: `https://api.yourdomain.com`
6. Сохраните

### Шаг 3: Перезапустить деплой фронтенда

После обновления секрета:

**Вариант 1: Автоматически**
- Сделайте любой commit и push в ветку `feature/DeploDocker`
- GitHub Actions автоматически пересоберет и задеплоит фронтенд

**Вариант 2: Вручную**
- Зайдите в **Actions** → найдите последний workflow "Deploy Frontend"
- Нажмите **Re-run jobs**

## 🔍 Проверка

После деплоя:

1. Откройте ваш фронтенд: `https://oxygen-sensor-frontend.pages.dev`
2. Откройте Developer Tools (F12) → Console
3. Должны видеть успешные запросы к API
4. Если видите ошибки CORS - проверьте настройки CORS в бэкенде

## 📝 Текущие настройки

- **Ваш Mac IP:** `192.168.2.170`
- **Локальный API:** `http://192.168.2.170:8080`
- **Cloudflare Tunnel:** нужно настроить маршрутизацию

## ⚠️ Важно

- Если используете локальный IP (`192.168.2.170`) - фронтенд будет работать только в вашей локальной сети
- Для работы из интернета нужно использовать Cloudflare Tunnel URL
- После изменения секрета, фронтенд нужно пересобрать
